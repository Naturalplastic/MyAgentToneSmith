# input/

批处理输入目录。本文件说明此目录的约定。

## 约定

- **图片**：`.jpg`、`.jpeg`、`.png`、`.webp`、`.bmp`、`.tif`、`.heic`
- **指令**：在图片旁边放置同名 `.txt` 文件，文件内容为该图片的调色指令
  - 以 `#` 开头的行视为注释
  - 可以写多行
- **没有同名 txt 的图片**：使用命令行 `-p` 参数指定的默认指令
- **txt 文件存在但内容为空**：同样回退到默认指令

示例：

```
input/
  照片A.jpg
  照片A.txt        # 注释行
                   帮我进行coser界通用的基本照片调光
  照片B.jpg        无同名 txt，使用 -p 指定的默认指令
```

## 使用

```bash
python -m mytone.batch --dry-run -p "默认指令"    # 列出执行计划
python -m mytone.batch -p "默认指令"              # 执行
```

产物写入 `runs/batch_<时间戳>/`。每个任务一个子目录，外加一份 `index.md` 汇总表。
单张任务失败不中断整批。

## 版本控制

本目录下的图片与指令 txt 均已列入 `.gitignore`，不会被提交。
仅本文件会被提交，用于保留目录结构。
